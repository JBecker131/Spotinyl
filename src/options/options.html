Spotivyn setup

Spotivyn talks to Spotify with your own developer credentials. This is a one-time setup and takes about five minutes.

  1. Copy your redirect URI

    Spotify needs to know where to send you back to. This value is unique to your installation.

  2. Create a Spotify app

    Open the Spotify developer dashboard, click Create app, give it any name, paste the redirect URI above into Redirect URIs, tick the Web API checkbox, and save.

  3. Paste the Client ID

    On your new app's settings page, copy the Client ID and paste it here. Leave the Client Secret alone — Spotivyn uses PKCE and never needs it.

  4. Connect

    Authorize Spotivyn to read and control your playback.

Controlling playback requires a Spotify Premium account — Spotify's API refuses play, pause, skip, and volume requests on free accounts. The now-playing display works either way.
